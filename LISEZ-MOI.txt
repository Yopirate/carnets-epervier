LES CARNETS DE L’ÉPERVIER v2.1 — IMPORT EBIRD

1. Sauvegarder d’abord tes données existantes depuis « Données & sauvegardes » > Exporter JSON.
2. Dans « Données & sauvegardes », rubrique « Importer mon historique eBird », choisir ton archive ZIP eBird ou MyEBirdData.csv.
3. Cliquer « Analyser le fichier » et lire les compteurs (aucun changement à ce stade).
4. Cliquer « Fusionner avec mes observations » pour ajouter les données sans effacer les observations existantes.
5. Exporter ensuite une sauvegarde JSON de l’ensemble des observations.

Pour GitHub Pages : extraire ce ZIP et copier les fichiers à la racine du dépôt carnets-epervier.
NE JAMAIS AJOUTER l’archive eBird personnelle, son CSV ou un export JSON privé au dépôt public GitHub.
Seuls les fichiers applicatifs de ce ZIP sont destinés à GitHub.

Notes : les noms d'espèces du CSV sont conservés tels quels; les noms scientifiques et identifiants eBird sont conservés dans la fiche structurée et dans les exports JSON. Les observations eBird sont stockées dans le navigateur local (localStorage) et ne sont ni transmises à GitHub ni synchronisées automatiquement. Le catalogue encyclopédique est principalement dédié aux rapaces ; les autres oiseaux eBird restent dans le journal. Le support ZIP utilise JSZip via CDN (connexion requise) ; en cas de blocage réseau, décompresser manuellement et importer le CSV.

Mise en garde : la carte topographique mondiale avec des milliers de points peut être lente. Photos et sons ne sont pas inclus dans l'export eBird.
